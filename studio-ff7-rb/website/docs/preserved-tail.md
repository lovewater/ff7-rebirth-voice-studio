# 正文头尾的整段原声

原日文字幕必须唯一、完整对应一段连续ASR词，正文两端落在可靠词边界。允许此前、此后存在额外ASR词或多块字轴未覆盖声音；正文中间仍有未覆盖声音则保留旧处理。只归一全半角、标点空白及平假名/片假名，不推测汉字读音，不按字数或ASR空档猜切口。

每个需要保留的头尾都须在其声音证据与正文之间找到至少250ms真实波形静音，切口落在静音内。正文匹配不唯一、任一必要切口不可靠时，不启用头尾整体保留，继续原流程。

原声前缀＋TTS正文＋原声后缀。头部从文件起点到切口、尾部从切口到文件末尾，分别作为未分类原声整体保留；无论笑声、环境音、其他声音或多少波形块，都不逐块分类，不为其补字幕。

正文ASR只取完整正文对应词，并减去前缀时长，使时间轴从正文槽起点计算。参考、拍数、朗读跨度、语速、改稿和TTS均只看正文；既有正文内分类和声学校验继续执行。参考PCM与字轴使用同一个正文相对坐标，避免前缀被重复偏移或误算作正文。

普通、斜体及正文降级线路先在扣除头尾后的正文槽内处理，再按原JP采样率、原起点复制两端PCM，不变速、不移动原声。正文偏短只在槽末补静音；超槽发声拒绝装配。仅50ms内且低于正文峰值0.5%的尾部余静音允许去除。最终总长与实际解码原音相同，两端PCM逐字节比对并保存SHA256。

为兼容尾部历史，保留日志步骤`preserved-tail`、`OnoPlan.preservedTail`及`conversion_meta.preserved_tail`、`fit.preserved_tail`。`startMs`仍是正文槽终点/尾部起点；新增可选`bodyStartMs`为正文槽起点/前缀终点，`bodyWordStart`为原始字轴中的正文起始词索引，缺省均为0。`headSha256`与`tailSha256`分别证明两端原声完整，`bodyStartFrame`记录最终正文原位置。旧音频、人工状态和旧运行不改写。
