# 正文后的整段原声

原日文字幕完整对应ASR字轴前缀、正文结束落在可靠词边界时，检查后方额外字轴或字轴外真实声音。正文中间仍有未覆盖声音则保留旧处理；不按字数比例、ASR空档或模型猜测定位正文终点。仅归一全半角、标点空白及平假名/片假名，不推测汉字读音。

正文之后存在至少250ms真实波形静音，才能在静音内确定切口。切口之后直到文件末尾作为一个未分类原声整体保留：无论笑声、环境音、其他声音或多少波形块，都不再逐块分类，不添加或恢复对应字幕。正文不完整或没有可靠静音切口时不启用，继续原流程。

正文ASR、参考音频、拍数、朗读跨度、语速和改稿反馈全部排除尾段。正文内既有拟声分类及声学校验仍执行。尾段不参与TTS，不因正文过长而移位、缩放或裁切。

普通、斜体及正文降级线路先在正文时间槽内完成处理，再使用原JP采样率将整段尾部PCM直接复制到原起点。偏短正文只在正文槽末补静音；超出尾段起点的发声拒绝装配。仅50ms内且低于正文峰值0.5%的尾部余静音允许去除，不截正文发声。最终总长与实际解码原音相同，尾段PCM逐字节比对，并保存SHA256。

日志步骤 `preserved-tail` 记录正文终点、首个尾段证据和实际切口。`OnoPlan.preservedTail` 是未分类尾段，不伪装成拟声/环境音；最终音频 `conversion_meta.preserved_tail` 和 `fit.preserved_tail` 记录来源、起点及PCM校验。旧候选、人工状态和旧运行不改写。
