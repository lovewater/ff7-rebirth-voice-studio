# 手动两端对齐：以生成音频段数为准

手动“高级自动对齐”和试听“自动调整”共用 `gapOnlyAlignmentPlan`。普通“自动对齐”仍只移动整句开口，不负责调整内部间距。

先用当前生成音频判断是两段还是三段，检测仍按原始整句峰值5%、10ms窗、至少250ms连续低电平的内部停顿；此前约定的孤立微弱凸起过滤同样生效。

生成音频是两段时，即使日文有三段或更多段，也只取日文**最长的合格内部停顿**作为唯一分界，把其余日文段归入前后两组。相同长度时取较早的一处，片头片尾静音不参与竞争。选中的最长停顿用于确定两组结构，不要求最终中文中间静音等于它的原始长度。

然后保持中文两段正文原PCM和时长：第一段开口贴日文第一组开口，第二段结束贴日文最后一组结束，剩余时间作为唯一中间留白。总长保持日文总长，不拉伸、不截正文、不改音量；其他中文段内停顿完整保留。正文放不下时仍拒绝。

生成音频是三段时继续使用原三段对应策略：日文也须三段，首段贴头、末段贴尾，中段按对应日文中段中心对齐。不会反过来把三段中文强行合成两段。

此规则仅限真人手动工具。`internalSpeechParts` 的自动/旧调用仍只接受实际两段或三段，`speechChunks`、大模型自动分段/拉伸/拼装、净语速计算均不受此次改动影响。后续维护不能把手动“按最长停顿归两组”推广到大模型入口。
