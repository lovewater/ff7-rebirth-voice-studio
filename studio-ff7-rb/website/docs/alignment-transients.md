# 对时忽略孤立微弱凸起

普通自动对齐、高级自动对齐、自动调整按钮，以及大模型候选的分段检测、自动拉伸、最终组装和朗读跨度检查，统一使用 `src/lib/alignment-transients.ts`。规则仅用于对时，不用于净语速、VAD、ASR及其缓存。

以原始整句绝对峰值为基准，只有同时满足以下条件才忽略：

- 凸起峰值不超过整句峰值的10%。
- 累计超过5%门槛的采样时长不超过20ms。
- 前后各有至少50ms连续幅度不超过整句峰值5%的实际音频。

20ms指累计越线时长，不是首末越线点之间的跨度。越线点之间不足50ms的低电平归入同一凸起，共同检查峰值及累计时长，避免把连续轻声拆碎后误删。首尾没有足够实际静音时保留；不补虚拟静音。不循环过滤、不重算峰值，边界按采样率换算，10%比较使用Float32精度。

函数返回对时检测副本和被忽略范围，原PCM不变。音频裁边、分段和拉伸仍取原PCM；被忽略的开头/结尾声音可能随既有首尾裁切离开成品，此规则不是降噪处理。原有0.5%保守保音裁边另有用途，保持原规则。按钮读取已加载的当前日文波形，避免旧起点缓存绕过本规则；clone的对齐目标同样读取当前日文参考。

问题案例：日文前置凸起约89.5～139.5ms，累计越线约0.7ms、峰值约6.2%；原检测误当开口，实际正文约452.1ms开始。旧成品及锁定不批量改写，后续对齐或生成时生效。
