# 两段正文自动运行约定

适用对象：场景演出自动运行的正常线路。快速原稿通道与整句 fallback 继续独立处理；手动 Zero-shot 不强制套用本规则。

## 入口

先按已有流程取得日文 Seed-ASR、区分正文与原声情绪/拟声/环境音，再制作实际 TTS 参考：删除拟声/环境音，裁首尾静音，保留内部静音。用这份参考的波形决定是否进入两段线路。

波形采用全局峰值5%阈值、10ms窗；整窗采样均低于阈值才算静音。内部有且仅有一处连续至少350ms长停顿，前后都有声音，进入“两段正文”。首尾留白不计，不按照字幕标点数量或ASR分句数量进入。去掉情绪原声后只有一段正文，就不强迫正文分成两段。

中文合成必须实际恰好两段，中文长停顿识别下限250ms。逗号、句号、回车、省略号是提示建议，空格等也可；程序不强制分隔符，最终看波形。

## 三个状态

这里说的是“两段时序状态”，独立于列表既有的拍数比/语速报警和人工异常。

- **正确 correct**：前、后段分别在85%～115%的时长缩放范围内对齐日文对应段；仅容许一个采样的舍入误差。
- **警告 warning**：缩放后无法完全对齐，但每段绝对余差均不超过300ms。是可用候选，但还要通过校字、比等原有检查和最终等长硬门槛。
- **错误 error**：任一段缩放后余差超过300ms、中文实际段数错误、正文放不下至少250ms中间静音，或最终无法组装成与原日文等长。

85%～115%是“输出时长/输入时长”，不是语速倍率。1.15表示拉长15%。300ms是逐段余差容差，不能当作最终文件总长容差。

若可用候选只有警告、没有正确结果，则保留警告稿，再请模型改善一轮。额外一轮不再递归触发“再多一轮”；新稿失败仍可选回旧稿。存在正确稿时优先正确稿；同等级候选保持校字疑点优先，再比较两段节奏。

错误需继续调整断句/必要的正文表达并重合成。结构/组装错误最多累计10个失败批次，与既有三轮语义改写及一次警告改善分开计数。耗尽仍保留可播放音频，但明确待人工复核，不能伪装合格。

## 最终组装硬门槛

以完整日文原音频解码后的采样长度为准，而不是数据库里取整后的时长。对应输出采样率换算后最多允许一个采样的舍入误差。

正文先逐段缩放，首尾留白参照完整原日文，中间静音填为剩余长度，并且至少250ms。最终不能再整体拉伸；不能截掉正文或用额外尾静音掩盖错误。

只要拼不成等长成品，即便两段原本只是警告，也升级错误，持久化错误状态并把原因反馈模型改稿重试。重试耗尽留下的音频不承诺合格，仍有待人工复核标记。

有原声情绪的情况，情绪从日文复制、正文来自TTS，中间用静音组装；情绪不计入正文段数，不再次拉伸情绪声。若去掉情绪后只有一段正文，组装失败时只修这一段，不能强行改为两段。

## 模型输入与费用

每轮固定重发完整官方日文、最初中文字幕、前几句原始日中对话，强调它们是中心意思。历史改写不是新原意，不许逐轮删掉否定、条件、数量、人物关系或添加事实。先自然断句，必要改字也必须保持原意。

复用已有Seed字轴给日文两段文字和波形时间。不提供日文分段字数/拍数，不规定中文分段字数配额。后续轮提供已有中文实际分段结果和偏长/偏短建议。

结构及分段余差先用免费波形检查，不合格候选不送本地ASR或模型校字；中文校字仍用本地Qwen，只有最终选定确需拼接字轴时才请求Seed。

## 情绪与招呼例外

独立的“ううん/うう—不”“ああ—嗯”等情绪应答允许语义对应保留日文原声，不要求中日同音；中日正文与TTS文字均去掉该部分，最终字幕恢复原中文词。不能把后面的实词一起删掉。

“ねえ/ねぇ/ねー”及拖长写法是招呼/征询正文，保留在参考及TTS正文中，不抽出日文原声拼回中文。找不到直译字时由中文上下文自然表达。ASR漏识时按缺失正文处理，不猜成拟声或环境音。

## 代码与日志入口

- `src/lib/auto-run.ts`：分支入口、错误重试、警告额外一轮、旧稿保留、最终等长校验。
- `src/lib/auto-run-part-alignment.ts`：状态定义、逐段WSOLA、最小间隔、等长组装。
- `src/lib/auto-run-two-parts.ts`：逐句并发上下文、固定中心意思、提示词输入、节奏排序。
- `src/app/api/lines/[stem]/tts/clone/route.ts`：只对正常自动流程的预处理参考执行逐段缩放，三条候选都留给后续评判。
- 提示词库 `two-parts.*`：关联为“两段正文自动对齐”分组，描述列明输入字段和例子。
- 日志 `two-parts-part-stretch`、`two-parts-warning-retry`、`two-parts-assembly-error`、`two-parts-final-structure`。
- `conversion_meta.auto_run_gap_alignment`保存分段状态、实际缩放比例和余差；`two_parts_assembly`保存最终组装错误。
