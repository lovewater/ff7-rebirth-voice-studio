# 每轮改稿的语速软参考

普通场景工作流按同一候选正文的既有测量保存净语速、归一拍数比、跨度比及综合描述。AsyncLocalStorage隔离并发句子及完整模型重跑，每条证据保留音频ID和原稿，后续改稿不能继承上一稿的合格状态。

每轮改稿/分段修复/兜底改稿附最近六条测量；最终润色只附被选中原始候选的测量。润色格式纠正仍保留同一证据。尚无对应音频时明确缺测，不预测或编造数据。最终择优继续使用各候选自身的字段。

使用selectionSpeed共享描述及既有正常区间。提示强调这是软参考，服从原有修改权限、校字、分段、时长、硬限及联合改稿规则；偏快不靠堆标点或长停顿掩盖吐字速度，已有标点如实识别，无明显改善原样保留。无新增自动淘汰、缩字或重试条件，净语速计算和门槛不变。
