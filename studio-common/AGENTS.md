# FF7 共用程序

Rebirth/Remake共用website与worker源代码，各自保留数据库、音频根和游戏资源适配。新站必须设置FF7_GAME_ID=remake、独立DATABASE_URL并校验音频目录.ff7-game.json；禁止连接或回落到Rebirth数据库。

场景演出支持两/三/四段，四段沿用三段的逐段核字、85%～115%缩放、300ms余差和最终总长验收；两个中段分别中心对齐。非演出使用独立总长流程。详见docs/。

processing_state=skipped不进入列表、统计、自动生成及MOD选择；保留历史选择，详情可取消跳过。ASR词组纠错与TTS读音配置分开。

代码存在不代表授权启动推理或批次，按用户指定范围执行；有人工选择时优先保留。禁止提交真实配置、数据库、游戏资源、音频、权重、缓存或运行日志。发布前遵守根AGENTS.md的工作树/索引安全检查。
