# 时长改稿的软字数建议

只针对同一音频已核字、切口可靠且时长失败的稿，按当前中文纯汉字数×参考正文时长/中文正文时长估算，取上下整数作为建议范围。偏短范围至少增加1字，偏长至少减少1字；明确给增减量，并优先尝试更接近原稿的一端。正常稿不主动扩写或缩字，不新增字数验收门槛。

线上单句使用含段内停顿的既有朗读跨度，两三段使用已有可靠逐段原始/参考时长，仅估计失败段。净语速计算及所有硬门槛不变。旧版本兼容字段须显式标legacy-net-speech，不能冒称新朗读跨度；缺值不推算。

缺测、漏字、稿件ID不一致、中文包含缺少读法的数字英文、分段边界不可靠、实测方向矛盾及过快/字数反馈冲突时不提供建议。allowRewrite=false时只保留诊断，不输出增减字的行动提示；原有逐段等字数润色权限不变。

建议只是表达长度参考，不是精确时长预测、最低字数或硬上限。自然准确时可偏离，不为凑数重复含义、堆修饰或标点；保留核心含义允许自然补全或合并表达。每稿仍重新TTS、核字、检查时长与组装。

回放C3330妈妈句旧测量：4字、0.768秒与参考1.133秒，建议5–6字、增加1–2字；优先较小改动。仅说明该音频的估算，不把旧音频判定套给新稿。
