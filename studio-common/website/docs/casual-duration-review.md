# 普通对话原稿与时长审核工作流

`executeCasualDurationReview(runId, stem)` 是显式批次入口，适用于已确认范围的 `field` / `unknown` 普通对话，不替换场景演出的自动流程。先由 `startAutoRun` 建立运行；批处理保持历史去重，任何已有人工锁定或异常均跳过。

0. 先识别整句纯语气、呼声和拟声：包括“喂、嗯、哎呀、呀呼”等，直接复制并锁定日文原声，字幕不改，不进入TTS/ASR/模型或人工异常流程。日文字幕可以为空，不再要求中日元音一致。夹有实际正文的句子不按纯语气处理。
1. 从 `lines.text_zh` 原稿合成一次，自然语速，不分段重组、不拉伸、不补时间槽。保留现有多余首尾静音清理。
2. 用 Qwen ASR 核对当前朗读稿。正文逐字一致可直接核过；有差异则由当前模型辨别近音、漏字、多字、重复或无关替换。
3. 核字通过且保存音频的实测总长小于或等于原日文音频总长，自动验收通过；不以拍数、净发声长度或数据库四舍五入时长代替此门槛。
4. 正文完整但超时，向当前模型提供原稿、当前稿、上下文、原日英字幕、实际时长和目标时长，压缩字数后重合成。游戏固定词仍需完整保留。核字失败则重读当前稿，避免用删字掩盖漏读。
5. 首次合成之后最多三次反馈，总计最多四次合成；达到条件即停止。模型失败或无法再压缩时保留已有音频及具体原因，不切换第二模型扩大预算。
6. 无论自动通过或未过，最终成品统一标为 `review_state='abnormal'`，供人工逐条审核；日志保留自动验收结论，失败不冒充通过。未过时优先选择完整读出且超时最少的候选；全漏字则保留最近一条。所有中间候选收在最终成品下。

台词保持原章节和区域。通过列表的“人工异常”筛选集中审核。处理期间新增的人工标记优先，结束回调不会清除或替换它；已锁定日文的纯语气条目不属于本流程。

此入口继承调用者的模型上下文，TTS 与 ASR 不随改稿模型切换。具体批次清单、队列、模型连接、凭证和音频属于本机运行数据，不放入源代码仓库。

## 斜体场景台词

斜体从自动入口直接共用自然语速时长流程，绕过日文Seed-ASR、拟声分类、拍数和分段对口型；完整原话不超长即结束，超长才缩字，最多三次反馈。场景斜体保留通常的候选/自动验收状态，不套用特定补录批次“全部人工异常”的收尾策略。已有人工标记保持；整句纯语气仍优先直接锁日文。
