# 拼接成品及派生编辑的字幕继承

subtitle_text为空表示沿用游戏原字幕，不表示取tts_text/spoken_text。朗读稿可能不含拼回原声的“嗯、哼”等；自动恢复后若与原稿相同，收尾会清空覆盖，这属于正常行为。

锁定时沿audio-edit的source_id追溯已结束自动任务的selected_tts_id，即使派生记录没有auto_run_id也应继承原字幕。仅同句、同tts_text和spoken_text的ready音频可继续追溯，限制32层、防环并验证来源ID；不能因为正文子音频带auto_run_id就视为完整成品。普通手动TTS差异仍需确认，显式手工字幕仍优先。

自动/手动改稿的邻句上下文也从覆盖字幕或原字幕取值，不使用去语气词的朗读稿。补充语音资源打包同样优先覆盖字幕和已有原字幕，仅确无原字幕时才使用TTS稿。本次不回写历史字幕、不修改锁定或音频。

回归例：67635拼回0–350ms语气声，恢复“嗯，你说得对”，与原文相同后覆盖为空。派生G版本68494过去失去自动成品身份，会错误提议“你说得对”；修复后无需同步删减字幕，强制核对时仍展示完整原稿。
