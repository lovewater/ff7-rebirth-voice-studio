# 最终择优的跨度、净语速与拍数比

候选JSON在原`ttsId/spoken/asr/paceRatio`基础上增加`netSpeech`、`beat`、`speedDescription`、`speedEvidenceComplete`及测量范围说明。数值来自同一候选已经测得的去情绪正文，直接随候选流转，不用跨度比推测净语速，不重算拍数或补造测量。最终拼装可能继续编辑音频，这些字段明确描述候选正文阶段。

`paceRatio`为中文朗读跨度除以日文参考跨度。段内自然停顿计入；多段取对应各段跨度之和，不含首尾和段间留白。1.10是中文跨度长10%，0.90是短10%，不是音节/秒，也不是归一拍数比，接近1不代表吐字正常。

净语速正常范围引用现有正常区间常量，低于下限偏慢，高于上限偏快，含边界。拍数比使用normalizedRatio及本句现有autoBeatBand；比低于下限表示中文偏长、同槽可能偏快，比高于上限表示中文偏短、同槽可能偏慢。单独豁免及原因仍显示，豁免不抹掉可计算的比值诊断。

| 净语速 | 比值方向 | 综合描述 |
|---|---|---|
| 偏快 | 中文偏长 | 速度有些过快 |
| 偏慢 | 中文偏短 | 速度有些过慢 |
| 两项仅一项偏快方向 | 另一项正常 | 速度有些稍快 |
| 两项仅一项偏慢方向 | 另一项正常 | 速度有些稍慢 |
| 正常 | 正常 | 语速正常 |
| 偏快 | 中文偏短 | 语速有点奇怪 |
| 偏慢 | 中文偏长 | 语速有点奇怪 |

短句比不可计算或净语速缺失时不补作1/正常，speedEvidenceComplete=false。若已有一项异常，仅按该项标稍快/稍慢；无异常但证据不全标“语速数据不足”，不声称两项正常。

提示词迁移089解释这些字段，并把“这些候选字和语速都已经过关”改为“通过前置检查，不代表处于正常区间”。只提供择优证据，不新增硬门槛、不改变预筛选顺序，不编造音色/情绪听感，不能挑回已淘汰候选。单候选仍直接选择，不强制增加模型请求；多候选综合自然表达、接话、语速和已提供的时序证据，不只比谁的paceRatio更接近1。
