# 字轴220ms容错与自动正文分段确认

漏识别声音候选与切口验证共用JP_WORD_AXIS_TOLERANCE_MS=220，替代180ms。只扩大基于已有字轴的搜索/屏蔽区；原有波形5%门槛、静音长度与切口声学验证仍保留，不按时间戳直接切音频。

进入两/三段自动正文前，按buildSpeechReference.kept实际保留PCM区间映射最初Seed字轴。每块波形必须有独立正文词支持；一个词不能支持两块，被删除范围切开的词不用于证明分段。utterance数量不设硬门槛，一个utterance里的真实两/三段仍支持。已忽略短环境音的词不计正文依据。参考重识别新出现的字不反向证明原先未确认声音是正文。

仍存在无正文依据的声音块时，记录reference-word-evidence并进入现有整句反馈降级，不强制拆中文、不擅自删除或保留某类声音。进入该检查前仍走既有语气/背景分类和安全切口验证。

回归C3330_MAIN_3800_0200_00_cld：原Seed首字1670ms，正文声学起点约1460ms，偏差210ms；180ms边界把候选右边界推到1490ms正文内，误判无谷。220ms后可正确取到80–200ms候选并交语义分类；若未确认，这块没有原字轴正文，不能再把“没事”硬拆成“没，事”。

不改净语速、语速范围、拉伸算法、人工工具的纯波形对齐或旧锁定。单段参考不新增多段门槛。所有候选与旧锁保留。
