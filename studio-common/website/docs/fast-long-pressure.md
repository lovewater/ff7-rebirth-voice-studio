# 偏快与中文偏长联合要求精简

中文净语速正常区间继续使用 `normal-speed-beat.ts` 的 `NORMAL_CHINESE_BEAT_SPEED_LOW/HIGH`，比较和改稿提示均引用同源常量，不单独维护数值。净语速测量、正常区间和原绝对硬上限不变。

普通场景候选满足以下全部条件时，不直接入围，按已有改稿预算要求精简，再TTS、核字和实测：已核字、目标分片与切口对应可靠；原绝对硬上限启用且通过；净语速超过正常区间上限；本稿可靠的归一拍数比低于该句原有比值下限，说明中文偏长。比值单独豁免或仅作参考，不掩盖此组合。比值必须是normalizedRatio，不能使用未归一比值或音频时长比。

正常范围内不触发；低于正常下限是偏慢，不触发减字；仅偏快而比值正常/偏高也不触发。日文不足8字本来不计算比，缺测或不可靠时不补造比值，因此不能以组合条件为由要求短句减字。校字或分片对应失败先修合成/结构。

反馈优先精简冗余并保留中心意思和自然停顿；同时音频偏短时，不再反向让模型增字或用长空白掩盖语速。仍遵守当前改字权限和分片协议。单独比值未过的自然标点尝试不截走已触发组合的候选。重试耗尽保留旧候选待复核，不将其伪装通过。

新元数据 `speed_beat_pressure` 和事件 `fast-and-long` 记录同一候选的速率、正常区间、归一比及原有下限。此处检查普通自动流程的候选阶段；既有成品、批量重处理产物及手动编辑不自动重跑。斜体独立流程保持原TTS错误/最终总长上限重试条件，不新增斜体语速或比值硬检查。

提示词版本由迁移088添加，key为 `rewrite.fast-long-pressure`；运行时以normal_low/normal_high占位符传入同源常量，模板里的示例不是第二套阈值。代码与测量逻辑分离，便于回看、调整正常区间或回退。

迁移同时为九个相关系统模板追加联合例外，明确优先于旧“比仅参考、不得据此缩短”的单独豁免表述；保留原模板历史。回退须同时停用fast-and-long-rewrite-v1和fast-and-long-system-v1:*新模板。
