# 游戏固定表达

独立表game_fixed_terms存词组和备注，090迁移幂等加入“再结合”“回归星球”。pronunciations第三tab提供新增、编辑、删除，独立链接?tab=game_terms；前两tab分别?tab=reference、?tab=tts_pinyin，直达、刷新、前进后退均由URL驱动。

发送创作请求前读取本句数据库原中文及消息中明确的当前中文字段，去掉Unicode标点、符号和空白后逐词匹配；跨标点换行也会命中。原稿始终参与，防止某轮误删术语后保护失效。不扫描邻句、外语译文或非结构化解释，不做同义词扩展、繁简转换，不强加未命中词。

最终callChatCompletion入口在模板解析后追加保护指令，覆盖自动各轮、手动改稿、两三段修复、时长降级和直接调用的最终润色。要求命中词完整保留，允许调整周围文字和标点，不因字数/时长替换术语。每请求查库，无跨句词表缓存。校字、分类、择优和字幕排版不注入；不替换TTS读音，不回写字幕。此功能是模型改稿约束，不新增程序硬淘汰门槛。

词库API独立/api/game-terms，词组规范化后1–80字符，备注最多500字符，重复返回409。原pronunciations表和只读TTS拼音词库不变。
