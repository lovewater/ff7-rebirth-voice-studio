# 对时时长与净语速

对时指标为 `waveform-cn-reading-span-over-jp-reference-v2`：单句从首个发声到末个发声，段内自然停顿计入。两段/三段使用已确认的正文区域，各段分别计算跨度；段间留白不计入段内跨度，另由既有时间轴布局处理。参考与候选均来自实际去情绪正文，按本条峰值5%裁定首尾边界，不按ASR字轴或字幕字数猜时长。

中文/日文朗读跨度沿用0.85～1.15；短句仍有150ms绝对容差，分段仍沿用300ms警告容差。段数、分组校字、分段缩放85%～115%和段间至少250ms规则保持。多段逐段通过之后才检查整句，不能靠误差抵消。

校字、结构、候选时长、朗读跨度等通过的候选先实际装配验收，总长必须与日文解码后原音频相差不超过50ms，再进入最终择优。失败的候选独立排除，不带走其他已可用稿；合格成品仍按原有机制保留用于润色失败回退。斜体继续走独立自然时长分支，仅最终总长上限，不套此处等长与分段检查。

净语速算法、界面缓存、4.5～7正常范围、9音节/秒硬上限以及慢速识别原样保持。净时长不再用来强制中日对时。正文比较元数据新写 `reference_reading_ms/candidate_reading_ms/reading_duration_*`，注明 `silence_removed=false`；数据库历史净时长记录及版本含义不改写。拍数“比”仍是（日文拍÷中文拍）÷1.20。

只对后续任务生效。历史已锁定音频不重做、不自动解锁；旧候选供离线回放核验，不能把旧ASR或旧稿合格结论套给新TTS。
