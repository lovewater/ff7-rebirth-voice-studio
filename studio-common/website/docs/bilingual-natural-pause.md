# 日英停顿参考与中文自然断句

正式改写、两/三段整理、降级改写、斜体超长改写，以及合格成品的文字润色，加入同一条中文断句软建议：同时参考日文和英文的停顿作用、句式、语气及上下文，中文仍按自己的口语意群组织，不逐词复制任何一种语言的断点。

检查没有表演依据的前短后长：前段只剩短主语，后段承载几乎全部疑问和谓语时，可在当前权限内重新选择断点，让完整疑问或语气成分先说出来。不强求各段等长，不按字数均分，不拆词或固定搭配；确有欲言又止的表演依据时可以保留短主语后的停顿。

区分音频证据和文字线索：波形实测停顿才是声学证据，字幕标点、空格和换行不能直接作为实际停顿或可靠分段。缺少英文音频停顿、日文分段拍数或时轴时不补造数据。本改动不新增分段/字轴检测，也不把未达到正式分段门槛的句子自动改成多段流程。

所有建议服从当前分片数量、scriptPolicy、禁止改字、逐段等字数和禁止跨段移字等既有约束。单个大分片内可以移动自然停顿；不因此绕过已确认大分片的硬约束。输出协议、TTS、校字、时长、净语速、拍数比和最终组装规则不变。润色后的新稿仍须重新合成并完整验收。

实现：`rewrite-punctuation-hint.ts`的`BILINGUAL_PAUSE_HINT`与迁移`087_bilingual_natural_pause.sql`中的追加文案一致。模板新增`bilingual-natural-pause-v1:*`版本，保留旧版本；每次模型请求读取最新启用版本。直接调用模型的成品润色使用同一常量。回退时停用该前缀的新模板并回退润色代码，不删除历史。已生成的音频、旧锁定及历史结论不批量修改。
