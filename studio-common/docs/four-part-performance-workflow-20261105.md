## 自动流程

中文仍以250ms识别真实分片。四片恰好也要逐片Qwen核字和边界核对；多片先全文核字，再完整连续归为四组，每个原片段只能出现一次。保留原始ASR及现有ASR名字纠错证据。末轮切刀扩展为三个边界，三个词界及真实波形短缝都须可靠，补切后仍须逐片核字，不放松已有门槛。

各段分别85%～115%缩放，缩放后余差不超过300ms为警告，任何一段超过则失败。首段贴对应日文开头、末段贴结尾，中间第二、第三段分别对齐对应日文发声中心；受间隔预算约束时夹到可行位置。三个内部间隔均至少250ms。全部正文必须保留，间隔不足不能截音、不能整体变速掩盖分段错误。最终按既有流程恢复拟声/环境音并验收完整长度（容差±50ms）；无保留音分支按采样精确等长。四段测量、候选节奏排名和最终结构检查包含全部四段。
