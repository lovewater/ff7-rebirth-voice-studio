# 自动流程接口配置

导航 `/settings` 与 `GET/PUT /api/settings/auto-run-model` 配置各游戏独立库的默认模型和接口。连接ID为grok、primary（官方GLM）；未保存时沿环境变量与默认Grok。密钥只保存在本地私密库，不回显，留空保留，不写审计；URL禁止内嵌认证或查询串。

部署新版本前，在每款游戏独立库应用098迁移；既有实例不会因提交代码而自动应用迁移。配置读取无缓存，运行任务固定连接快照；新run创建和配置保存使用同一advisory lock，任务运行中禁止修改地址/模型/密钥，可调整未来默认连接。

同一任务三轮、子HTTP请求与分句重组均沿明确模型，不跨模型隐式回退；核字、时长、分段、额度和人工选择保护不变。公开源码不含实际配置，运行数据库及配置导出不得提交。
