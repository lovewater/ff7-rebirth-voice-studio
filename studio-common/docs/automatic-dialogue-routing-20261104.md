## 场景演出

`isPerformanceMode` 判定的 `scene` 和 `mixed` 使用场景流程，包括斜体场景。日文原声经过 Seed-ASR、参考正文处理，中文合成后核字、对口型和成品拼接验收。此前场景主体与整句降级中的斜体跳出已取消，斜体标记不再形成第三条自动流程。

三轮均使用 Grok，前两轮正常，第二轮最后一批仍明确分句结构失败时，第三轮才允许短缝补切。每轮最多 24 条原生 TTS，整项最多 72 条；scene/mixed 均受此限制，普通对话永远不能启用补切。

## 普通对话

任何其他 dialogue_mode（包括 field、unknown、战斗、声库、事件、空值及未来新增类型）统一使用 `runCasualDuration`，不按斜体另分流，不检查开口时间、逐段对齐或拍数比，不调用 Seed-ASR。

先以 Japanese Qwen-ASR 和可选 ForcedAligner 提供的字轴做保守本地首尾清理。官方文字证据、文字闭合、低能量间隙、字轴保护及清理参考独立复听不足时，保留完整原声和原稿。中文正文使用处理后的日文参考自然合成；启用清理时，正文核字前按[格式契约](casual-body-format-normalization-20261104.md)另存必要的24k标准版本，再对同一文件核字和回拼。预算为原日文完整实际时长扣除保留首尾；只允许正文在不超过 10% 的范围内保调缩短，缩短产物重新核字。通过后以原始 PCM 首尾回拼，总长不得超过完整日文原声（保留既有 1ms 采样舍入容差）。

原稿逐次单条最多三次，通过即停；之后最多三轮改稿反馈、每轮原生三条并逐条完整处理验收，见[裁边与三选一规则](casual-original-retries-and-edge-trim-20261104.md)。漏读沿用同稿重试，完整读出后仍超长才将实测时长反馈给 Grok 压缩正文。普通流程只有一轮，不进入场景的三轮模型/补切工作流。

所有普通类型均沿用原 field 的自动锁定标准：最终正文与提交时的当前原稿一致（仅忽略标点、符号、空白），核字与时长通过，且最终字幕沿用原稿。改稿、失败及人工明确复核的未通过项保留相应候选/人工异常状态。已有人工锁定或异常、人工修改字幕、核字后文件 SHA 变化等保护继续优先；拼接失败不能推荐正文半成品。

唱歌和纯语气等既有原声分流继续保留。实际解码 PCM 精确全零的日文原声沿用字节一致的原 JP 锁定，不依赖中文参考、不启动 TTS。

## 克隆接口

有 autoRunId 的 clone 请求只以 `isPerformanceMode` 决定是否对日文时间轴，不再将 unknown 等类型重新拉回对时。没有 autoRunId 的手动 clone 保持现有行为，未扩大改动手动生成策略。显式普通时长复核入口接受任意非场景类型，拒绝 scene/mixed。

本次实现验收使用 CPU/mock，不调用真实 TTS、ASR 或 LLM。200 条实测、部署及实测质量审查由本次主任务另行记录。
