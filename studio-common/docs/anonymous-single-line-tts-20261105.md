# 人物未知的单句中文制作

适用于已有真实日文语音、已识别正文及可用中文制作稿，但未关联说话人的条目，例如 `tk_town8_3392_0010_wm51_0`。人物姓名未知或 `lines.speaker=NULL` 均不能成为普通音频不参加制作的理由。

人物保持未知，不从相邻文件或通用编号猜同一个人、不新建虚构人物。Zero-shot 仅使用本句日文原声；若现有保守清理确认可拆拟声/环境边缘，则允许使用当前运行已登记的本句清理参考。匿名条目不接受邻句参考、中文参考或未登记的自定义参考。保存本句JP文件与参考文件SHA、路径及context=none，数据库097迁移允许带完整记录的匿名zeroshot-jp及audio-edit派生，保留人物外键。新版本首次INSERT即携带记录，不能先写空记录再补；自动对齐、缩放、PCM回拼及页面编辑派生继续保留记录。

普通单句流程沿用既有规则：

1. 首先判断整句纯拟声；真实全零日文亦按既有规则保留原声。不能把ASR为空直接当纯拟声。
2. 有原中文用原中文；无原中文以已完成且来源/SHA闭合的日文识别→中译为制作起稿，不写成官方原稿，不添加邻句上下文。
3. 自然合成当前稿，按现有整句自动对齐处理，并对实际成品核字；必要时仅缩发声跨度、最多15%，首尾静音固定。JP拟声/环境原声先扣预算且不参加变速，最后原PCM拼回。
4. 处理后完整成品仍超原JP总长（1ms采样容差）则同稿有限重试，起稿共最多3次。
5. 仍失败且存在核字完整但超长的实际成品，才按实测秒数和文字预算交大模型改稿，最多3轮，每轮生成3候选；每条均重新处理、核字、验时长及择优。不能为掩盖漏读删稿。
6. 改稿和独立终审均只提供本句日/英及已有中译参考，不读取前后邻句。无原中文分支沿用既有“不比较改写对不存在原稿的原意”规则，核字/读音/时长/人工优先及源SHA保护保留。合格后按现有规则实际锁定，未过保留候选和明确原因。

原错误的最终说明曾把「台词没有说话人」等三次生成入口失败笼统写为核字/时长失败。现在无任何可用候选时保留实际生成错误，不再宣称已经合成后时长未过。
