# ASR词语纠错

入口：`/pronunciations?tab=asr_corrections`。每款游戏使用自己的 `asr_word_corrections` 表；标准词下配置一组常见ASR别名，支持新增、修改、启用/停用、删除与纯文字预览。和已有 `pronunciations` / TTS发音替换表分开，规则不会进入TTS出站正文。

先应用 `092_asr_word_corrections.sql` 建表，再应用 `093_asr_main_character_aliases.sql` 初始化14组人物名。初始化使用 `ON CONFLICT DO NOTHING`，不会覆盖后续人工编辑。Remake以本库角色拥有表和序列；Rebirth仍使用原角色。每日全库pg_dump会包含新表，不共享两作数据。

纠错只用于当前待核朗读稿中标准词的对应位置。程序用完整正文做有界编辑对齐，别名转换不吞掉其他缺字、多字或重复；同等对齐优先少转换，纠错位置不唯一时保留原识别。例如“威吉发现危机”被识别为“危机发现危机”，只改第一个对应位置；正常“危机很严重”保持原样。只忽略标点/符号/空白，不做NFKC或通用同义词归一。

原始ASR、原始word时间轴、TTS稿、音频、游戏字幕保持不变。纠错结果、命中词组与位置、原始文字及SHA作为独立证据保存。普通与场景共用 `judgeSpokenText`；普通最终独立语义/读音门禁重新计算同一份规则，避免初审接受专名而终审再次否决。改写仍须原有语义验收；配置的人名别名不是忽略漏读的许可。自然儿化沿用旧规则。

场景逐片/归组核字也使用相同配置。切刀补救只在原有许可轮次启用；字轴仍是原始识别。若别名改变局部字轴字数（如13/十三），可用于文字核对，但不能据此猜切点，切刀保守拒绝。波形、时长及原声PCM门槛均不变。

每个运行读取本库规则快照，不以全局缓存切换并发请求。普通成品真正锁定前，在事务中重新检查已命中的规则；人工停用或修改导致命中变化时，不沿用旧核字证据自动锁定。
